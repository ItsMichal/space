# AGENTS.md (apps/halmic)

Rules and traps for working on halmic.com. Read the repo-root [`AGENTS.md`](../../AGENTS.md) first (shipping, commits,
identity rule, agent environment). Human overview, commands and deploy: [`README.md`](README.md).

This file is scanned by `npm run check:identity` like the rest of the app. Do not add the owner's name, initials or the
portfolio domain to it. Describe the other site as "the portfolio".

## Shape

Zero runtime dependencies. `build.mjs` renders `src/index.html` plus `content/*.json` and markdown (`md.mjs`) into `public/`.
One small Worker (`worker/index.js`) answers `/api/*` only; everything else is served from `public/`. `serve.mjs` is the
local static server (port 4310, `PORT=` to change). The package depends on `@space/crosslinks` only.

## `public/` is a mix, and it is tracked

- Hand-kept sources: `base.css`, `bold.css`, `page.css`, `switcher.css`, `app.js`, `hero.js`, `switcher.js`, fonts, images,
  `hero/*`, `previews/*`, `og/*`, `posts/*`.
- Generated by `build.mjs` (never hand-edit): every `*.html`, `404.html`, `sitemap.xml` (lastmod = build date), `rss.xml`,
  `robots.txt`, `llms.txt`, `_headers`, `icons.svg`, `previews/index.json`.
- Rules that follow:
  - After any change to `src/`, `content/`, `build.mjs`, CSS or JS, run `npm run build:halmic` and commit the output.
  - CSS and JS are linked as `?v=<content hash>`, so any CSS/JS change touches every HTML file. Two branches that both change
    them ALWAYS conflict in generated HTML. Resolve by merging `main`, taking either side of the generated files, re-running
    `npm run build:halmic` and committing. Never hand-merge generated files.
  - `sitemap.xml` changes on every build day; that diff is noise, not a bug.

## Page model

- Hero: inline SVG wordmark from `brand/wordmark-parts.json`, a status pill and a leaning-bar meter driven by `data-live` on
  `<html>`, and a WebGL highlights reel (`hero.js`, media in `public/hero/`, built by `brand/reel/`). The reel starts only
  after load, while the hero is visible and the tab is shown. It falls back to a poster for reduced motion, data saver, no
  WebGL, or refused autoplay. A portrait cut serves phones.
- Never edit the wordmark or anything in `brand/svg/`. They are generated geometry (`brand/build-logotype.mjs`).
- Below the hero are bentos: Watch (YouTube and Twitch mixed, round platform badges, the Special Force films lead), Play
  (Project Mountaintop leads), Work (Pokemon Phoenix Rising, the dental logo), Posts (`content/posts.json`; not rendered
  while empty), Elsewhere (X, Medium).
- Tile system: square-unit grid, sizes 1x1, 2x1, 2x2. Column count comes from the bento's own width (container query:
  4 from 880px, 3 from 640px, else 2). The single `data-flex` tile gets the width that fills the last row (`app.js`); a playing
  tile grows to 2x2. Stat tiles take their numbers from content, never typed in. Link tiles use brand colours; platform
  colours appear only on badges and link tiles. Click-to-play happens in place. Hover previews come from `public/previews/`.
- Icons: `icon('name')` returns an inline `<use>` into the generated sprite. Sources are Phosphor Fill (MIT) and Simple Icons
  (CC0) under `brand/icons/`, with their licences. To add one, copy only that SVG from the npm package (fetched into a temp
  dir, never added as a dependency) into the matching folder, rebuild, use `icon('name')`. Unknown names throw at build time.
  The Noun Project is a style reference only: copy nothing from it (licence).
- Fonts: "Halmic Display" is generated by `brand/type/build-display.py`. `--ship` writes a content-hashed woff2 into
  `public/fonts/`, deletes the old one, and rewrites the URL and `unicode-range` in `base.css` and the preload in `build.mjs`.
  The hash changes on every rebuild, so only ship when the font really changed.

## Content security policy (strict, generated in `build.mjs`)

`_headers` carries the CSP. Consequences for any change:

- No inline `<style>`, no `style="..."` attributes, no inline scripts. JS may set styles through CSSOM
  (`el.style.x = ...`). JSON-LD is a data block, which is allowed.
- Third parties are exactly: `static.cloudflareinsights.com` (script) and `cloudflareinsights.com` (connect) for Cloudflare Web
  Analytics, which the owner wants; frames from `www.youtube-nocookie.com` and `clips.twitch.tv`. `media-src 'self'`.
- Nothing else is requested from other hosts. Thumbnails, box art, post images, icons and fonts are local or proxied by the
  Worker. If you need a new external request, stop and ask.
- `scripts/check-links.mjs` (part of `npm test`) enforces several markup rules (no inline styles, local images, one h1, alt and
  sizes, resolvable links and icons, size budgets for previews).
- The only local way to exercise the real CSP and the Worker together is `wrangler dev` (see below). `serve.mjs` sends no CSP.

## Worker (`worker/index.js`)

- `/api/live`: Twitch Helix with an app token, edge-cached 45 s. `/api/clips`: top clips, cached 1 h. `/api/clip-thumb/<id>`
  and `/api/game-art/<id>`: same-origin image proxies, restricted to ids from the cached clips payload.
- Secrets `TWITCH_CLIENT_ID` and `TWITCH_CLIENT_SECRET` are set by the owner with `wrangler secret put`. Agents never handle
  the values. Without them the endpoints answer an "unknown" payload.
- Failures return an "unknown" payload, never a 5xx.
- Never call the global `fetch` through an object property (`deps.fetch(...)`): workerd throws "Illegal invocation". The code
  wraps it (`(...a) => fetch(...a)`). Unit tests inject a fake fetch, so they do NOT catch this regression.
- Cloudflare's zone Browser Cache TTL rewrites `max-age` on API responses to hours for browsers. The client therefore fetches
  `/api/*` with `cache: 'no-store'`. Keep it.
- Worker logs: Cloudflare dashboard, Workers, halmic, Observability.
- `workers_dev` and `preview_urls` are off in `wrangler.jsonc` on purpose; custom domains come from `routes`.

## Identity rule, applied here

The root guide has the rule and its exceptions. Practical points for this app:

- Run `npm run check:identity` before every commit that touches `src/`, `content/`, `public/`, `worker/` or `brand/`.
- `scripts/sync-youtube.mjs` holds back any video whose title or description trips the local deny list, writing it to
  `content/videos.held.json`. Do not publish held entries without the owner. `content/identity-denylist.txt` is that script's
  copy of the patterns; do not print or edit it.
- Posts: links to the owner's own X posts pass the check only in the exact status-URL form the library exempts. Never write
  the account handle as text.
- Media (video thumbnails, `hero/`, `previews/`, `posts/`, `og/`, `shots/`): view the frames. Known hazards: FIFA episode
  HUD cards with a surname, Special Force name credits, Twitch overlays with a handle. Crop them out or skip the item.

## Media pipelines

Only the owner's own published content is used (his YouTube channel, his Twitch clips). Sources are fetched with `yt-dlp` in a
venv under `$TMPDIR` and never enter the repo; only rendered outputs are committed. EDLs and scripts make them reproducible:
`brand/reel/` (hero reel, see its README) and `brand/previews/` (hover previews). Size budgets are enforced by
`check-links.mjs`. Keep `apps/halmic/shots/` small: JPEG, and delete superseded sets.

## Test and verify

```bash
npm test -w @space/halmic        # worker tests (node --test), check-links.mjs, check-social.mjs --dir public
npm run check:identity           # from the root
node apps/halmic/scripts/check-social.mjs https://halmic.com --ua=Twitterbot/1.0   # live social-card audit
npm run og -w @space/halmic      # rebuild public/og/*.jpg share cards (needs Chrome and sharp)
PORT=4563 node apps/halmic/serve.mjs &
node apps/halmic/scripts/check-holes.mjs http://localhost:4563   # bento packing; needs Chrome and a running server; NOT in npm test
```

- `scripts/shot.mjs <url> <out> <w> <h> [flags]` takes headless Chrome screenshots over CDP. Flags: `full`, `mobile`, `jpg`,
  `gl` (software WebGL, needed to see the reel), `nogl`, `rm` (reduced motion), `eval=<js>`, `click=<css>`, `hover=<css>`,
  `netlog`, `clip=x,y,w,h`, `sel=<css>`, a bare number for wait in ms. Chrome comes from `CHROME_PATH` or the macOS default;
  `ws` and `sharp` resolve from the root `node_modules`.
- Test overrides (not linked from the UI): `?live=1&game=<name>` forces the on-air look, `?live=0` offline;
  `?clips=demo&n=0..6` fake clips, `?clips=none` none; `?reelq=0..3` pins the reel quality.
- `.claude/launch.json` (local, gitignored) can run `halmic` (`npm run dev:halmic`, port 4310) and `halmic-worker`
  (`wrangler dev --cwd apps/halmic --port 8788`, the real `_headers` and Worker).
- Social cards: `scripts/build-og.mjs` writes `public/og/*.jpg`; `check-social.mjs` audits OG/Twitter tags and images for every
  sitemap URL, locally or live.

## Open items (verify before relying on them)

- Reddit research for Phoenix Rising was never done. reddit.com is blocked for the agent browser and curl, so
  `content/phoenix-rising.json` holds the subreddit as a link only.
- Only 4 X posts qualified for `content/posts.json`.
- A possible bento hole in Watch at about 800 px with exactly 3 clips was reported once and not confirmed. Run
  `check-holes.mjs` if you touch the grid.
- The hero reel has never been verified on a real GPU or on iOS by an agent. Only software WebGL and fallbacks were checked.
- `docs/*.md` are historical planning notes (discovery, design system, technical plan, SEO). Parts no longer match the site:
  Discord is gone, the "calm" direction is gone, and the technical plan describes a Next.js stack that was not built.
  Trust the code and this guide over them.
