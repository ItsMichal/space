# AGENTS.md (apps/michal-ai)

Conventions of the portfolio app. Read the repo-root [`AGENTS.md`](../../AGENTS.md) first (shipping, commits, identity,
environment). This file describes how the app already works; it does not set new rules. Other sessions often have open PRs
here, so keep diffs narrow and fetch before branching.

## Shape

- React Router 7 (framework mode, `ssr: false`) on Vite, React 19, Tailwind 3. Every route is prerendered to static HTML at build
  time (`react-router build` writes `build/client`) and served by the plain Worker `worker/index.ts` through the assets binding
  (`wrangler.jsonc`: Worker `space`, site https://michal.ai, Durable Objects `PresenceRoom` and `ReactionsRoom`). No Node at runtime.
  How it fits together and how it was proven equivalent to the old Next build: `docs/migration/`.
- Run everything from the repo root (`npm run dev:michal`, `npm run build:michal`, `npm run typecheck`, `npm run lint`,
  `npm test`) or with `npm run <script> -w @space/michal-ai`. Scripts assume the app root as `process.cwd()`.
- `@/` is the app-local import alias. Shared code comes from `@space/motion`, `@space/tokens`, `@space/crosslinks`
  (Vite compiles their TypeScript source with the app; see `ssr.noExternal` in `vite.config.mts`).
- Tests are vitest (`npm test -w @space/michal-ai`). `npm run typecheck` also checks `worker/tsconfig.json`.

## Content

- Posts are Markdown files in `content/posts/*.md` with front matter (`title`, `slug`, `kind: article|project`, a stable
  `id`, `description`, `date`, `tags`, `priority`, optional `draft`, `parent`). The `id` never changes when a slug is renamed;
  the live API and the crosslink pair map key on it.
- Old URLs are redirected from `content/redirects.json` (single hop, 308, built by `lib/redirects.mjs`). `npm run check:slugs`
  validates slugs and redirects.
- `content/profile.ts`, `hackathons.ts`, `press.ts` hold structured copy. `content/embed-status.json` is generated by
  `scripts/build-embeds.mjs` and committed.
- The writing tool and the design labs are dev-only routes: `app/routes.ts` adds them only under `react-router dev`
  (`/write` and friends, wrappers in `app/dev/`), and the file-writing API (`app/api/write/**/route.dev.ts`) is served by
  `vite/dev-api.ts`, a `serve`-only Vite plugin. Production builds never contain either (`lib/rr/routes.test.ts`). Deleted posts go to `content/.trash/` (gitignored), not away.
- No em dash or en dash anywhere in shipped copy or source (`npm run check:dashes`).

## Build pipeline

`npm run build` runs `prebuild` first: `scripts/build-images.mjs` (AVIF/WebP variants, share cards,
`lib/media/manifest.json`), `build-embeds.mjs`, `build-live-slugs.mjs` (writes `lib/presence/slugs.generated.ts`; a unit test
fails if the committed file drifts). The image outputs (`public/media/_v`, `_og`, the manifest, `.cache/build-images`) are
gitignored and cached in CI by `.github/actions/media-cache`. `npm run deploy` is the build then `wrangler deploy`;
CI does this, not agents. `npm run check:do` asserts the bundle exports the Durable Object classes. The build also renders the share cards
(`scripts/share-cards.ts`, satori + resvg) and writes `worker/redirects.generated.ts` from `content/redirects.json`.

## Live features

Article reactions and a view count are on; presence pins and paragraph reactions are off. Switches: `lib/presence/flag.ts`
and the Worker vars `LIVE_KILL` (emergency off, every `/api/live/*` answers 204), `VIEWS_PUBLIC`, `LIVE_BLOCK_REACTIONS`.
Details: `docs/presence.md`, `docs/live-reactions-views.md`.

## Design

The look is "Paper": see `docs/design-system/README.md` (tokens in `docs/design-system/tokens.json`;
`npm run tokens -w @space/michal-ai` regenerates `app/styles/tokens.css`). Backdrop, glass, motion and shader notes are in
`docs/backdrop.md` and the other files under `docs/`. Screenshot folders under `docs/` (`*-shots`) are reference material
from past passes.

## Social previews

`scripts/check-social.mjs` audits Open Graph and Twitter tags for every URL in the sitemap
(`node apps/michal-ai/scripts/check-social.mjs --dir <build dir>` or a live URL). It is the same script as halmic's copy, so
its `--twitter-site` default is halmic's account: pass `--twitter-site=` to skip that check or give the portfolio's account.
Cards are generated by the image build and `scripts/share-cards.ts` (served by the Worker at `/<route>/opengraph-image`).

## Identity

This is the owner's real-name site. It does not advertise the persona handle: `npm run check:identity` warns when shipped
copy mentions it outside `scripts/identity-allowlist.txt`. The logo switcher and paired post links come from
`@space/crosslinks`; do not add the sibling site anywhere else (metadata, JSON-LD, sitemap, feeds, footer credits).
