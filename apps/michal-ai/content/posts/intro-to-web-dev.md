On February 24, 2021 I ran an intro to modern web development workshop for Blueprint Boulder. The materials are four checkpoint files, each building directly on the one before.

Checkpoint 1 is a bare page: the doctype, `html`, `head`, `title`, a heading and a paragraph. Checkpoint 2 adds more tags and the idea of attributes, using a short bio site as the example. Checkpoint 3 is basic CSS in a `style` tag. Checkpoint 4 pulls in Bootstrap from a CDN to make the page look more professional.

The explanation lives in the files themselves, as HTML comments written for beginners. (The very first comment in Checkpoint 1 is about how comments work.) Open any checkpoint in a browser, and the file next to it explains what you're looking at.
