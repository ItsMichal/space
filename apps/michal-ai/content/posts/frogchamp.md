## Frogchamp- Superpowering Chat for Streamers

Frogchamp is a currently on hold initiative to create the best dashboard for streamers. The idea was to take advancements in LLMs and my web dev knowledge to create a hub that allowed big and small streamers to get realtime insights on chat behavior, sentiment, and metrics, and use LLMs to boil down as many data points into a sentence-length overviews and recommendations.

Currently, I implemented a few of the modular components, but have yet to add the AI powered metrics and implement a proper backend. This project is on hold until I can find time to work on it again, but it is live at the link below.
