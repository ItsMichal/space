# Credits and licenses

## Code
No third-party shader code is copied into this repository. The GLSL in `components/shader-image/` and `components/backdrop/` is original. Techniques that informed it are listed with URLs and licenses in `research.md`. Notable influences: Codrops (Kohlbach 2024 DOM/WebGL sync; OGL progressive blur), Maxime Heckel (dithering), Inigo Quilez (value noise, fbm), Jorge Jimenez (interleaved gradient noise), Jarzynski and Olano (PCG hash), Curtis et al. 1997 (watercolor), Secord 2002 (stippling), the Godot CC0 wind-sway shader, Paper Shaders (Apache-2.0).

Rules: copy only code that is MIT, Apache-2.0, BSD or CC0 and keep its notice here and in a comment; never copy from lygia (Prosperity license) or Shadertoy without an explicit permissive header.
