# ProjectRow

One piece of work in the index: title and one-line description on the left, a serif `spec` line (year · stack · role) beneath or to the right, a `hairline` above. The featured project above the index gets a large image instead.

**Consumer provides** title (no emoji), one specific sentence, year, up to four stack items, role, image and href. The whole row is the link; the title turns `accent` on hover. On phones the image shows inline (never hover-only) and the spec line sits under the description.
