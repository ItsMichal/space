# ProjectRow

One piece of work in a list: title and one-line description on the left, year and tags in `meta` on the right, a `hairline` above. Replaces the old project cards.

**Consumer provides** title (no emoji), description (one sentence), year, up to four tags, and the href. The whole row is the link; the title turns `accent` on hover. On phones meta moves under the description. Lists close with a final `hairline`.
