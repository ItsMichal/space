# GlassButton

A pill-shaped liquid glass button for primary actions on the page (Resume, GitHub, LinkedIn, Publish).

**Consumer provides** the label (sentence case, one or two words), optional leading Lucide icon at 20px, and an `href` or click handler. Classes: `lg lg--pill lg-btn`. Use `lg-btn--solid` (ink fill, no glass) for the single most important action on a screen — e.g. Publish in the editor.

Hover scales to 1.03, press to 0.97 on a spring; reduced motion disables both. Focus shows the `focus` ring.
