Building arcade controllers for a rhythm game

I soldered the controllers before I wrote a single line of the game.

Project Mountaintop started as a question about feel: what does a rhythm game play like when the buttons are yours? The answer took a MIDI pipeline, an Arduino and a lot of trial and error.

The MIDI system

Every note in the soundtrack is authored once and drives both audio and gameplay, so NoteSpawner never drifts from the music.
